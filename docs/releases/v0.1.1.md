# Endurance Agent Lab v0.1.1

Endurance Agent Lab v0.1.1 is an engineering-quality patch release. It makes the existing quality gates reproducible in development and CI and does not change coaching behavior or public benchmark semantics.

## What changed

- Development and CI installations now include the optional OpenAI SDK, allowing strict mypy to check the OpenAI adapter while the core package keeps OpenAI optional.
- Ruff lint and formatting findings are resolved with behavior-preserving standard-library and annotation updates.
- Strict mypy narrowing is explicit in Markdown rendering, optional training-date handling, CLI context loading, schema export, and OpenAI request typing.
- Focused regression coverage now exercises those paths.

## Compatibility and reproducibility

- EnduranceBench v0.1 remains at version `0.1.0` with the same 30 cases and 30/30 rules-provider baseline.
- Claim code meanings and rules-provider decision logic are unchanged.
- The seven public JSON Schema contracts remain unchanged at schema version `1.0`.
- The `training-plan-auditor` Skill content is unchanged (`50b61e48de53`).
- Core installations still do not require the OpenAI SDK; it remains available through the `openai` extra and is now also included by the `dev` extra.
