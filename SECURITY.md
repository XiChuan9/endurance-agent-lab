# Security Policy

Report vulnerabilities privately to the maintainers before public disclosure. Include affected version, reproduction steps, impact, and any suggested mitigation.

Security-sensitive areas include API-key handling, path traversal in imported files, private athlete data leakage, untrusted HTML/report content, dependency compromise, and provider responses containing secrets.

The project does not execute model-generated code. Skill scripts are repository-controlled and should be reviewed like ordinary source code.
